### ROLE
Act as a Senior Product Designer specializing in Android Native development and Material Design 3 (Material You) design systems. Your goal is to generate high-fidelity, professional UI/UX prototypes for a premium Android application.

### PROJECT CONTEXT
Project Name: "Multiverse Explorer" (Rick and Morty API Client).
Objective: A highly polished, performance-oriented mobile client for the Rick and Morty API. This is a recruitment technical test, so the design must demonstrate mastery of Material 3 Expressive guidelines, sophisticated typography, and seamless user flows.

### DESIGN LANGUAGE: MATERIAL 3 EXPRESSIVE
- Visual Identity: Sci-fi meets modern minimalism. Use a sophisticated color palette derived from the "Rick and Morty" universe (Portal Green, Space Black, Cosmic Violet) but applied through Material 3 Dynamic Color (M3) logic.
- Layout: Adaptive Android layouts with proper use of safe areas, edge-to-edge design, and generous whitespace.
- Typography: Use expressive, variable font hierarchies (e.g., Roboto Flex or Inter). High contrast between display headings and functional body text.
- Components: M3 components (Cards, Navigation Bars, FABs, Search Bars) with varied corner radii to reflect the "Expressive" style. Use subtle shadows and depth (Elevation) instead of heavy borders.
- Imagery: High-quality character portraits with smooth clipping masks and adaptive background colors based on the character's primary color (Dynamic Color extraction).

### USER FLOW & SCREEN REQUIREMENTS
Generate a cohesive set of high-fidelity screens:

1. Splash Screen: 
   - Minimalist, brand-focused. 
   - Centralized animated logo placement with a subtle cosmic background texture.

2. Character Discovery (Home/List Screen):
   - A sophisticated list or staggered grid of characters.
   - M3 Search Bar integrated into the top app bar.
   - Filter chips (Status: Alive/Dead, Species, Gender) using M3 Filter Chip components.
   - Rich Card design: Each card shows the character's portrait, name, and a subtle status indicator.

3. Character Detail Screen (Immersive View):
   - An "Expressive" immersive layout where the character's image dominates the top half (using a collapsing toolbar pattern).
   - Transition-ready design: The card from the list should visually expand into this view.
   - Content: Detailed bio, origin, and "last known location" using M3 List items and structured typography.
   - A prominent, playful Floating Action Button (FAB) for "Favorite" action.

### TECHNICAL SPECIFICATIONS FOR OUTPUT
- Aspect Ratio: 9:19.5 (Modern Android devices).
- Style: Clean, Flat-ish but with depth, highly legible.
- No clutter: Focus on "Less is more" while maintaining the sci-fi essence.
- Provide a consistent design system look across all screens (unified color tokens and spacing).
